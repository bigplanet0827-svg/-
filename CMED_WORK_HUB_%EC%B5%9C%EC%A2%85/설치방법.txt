CMED WORK HUB 설치 안내

주의: Index.html만 PC에서 더블클릭하면 사이트 목록이 불러와지지 않습니다.
이 파일은 Google Apps Script 웹 앱 안에서 작동하도록 만든 파일입니다.

[최초 설치]
1. 회사 공용 Google 계정으로 https://script.google.com 에 접속합니다.
2. 새 프로젝트 생성 -> Code.gs 내용을 제공한 Code.gs 파일 내용으로 전부 교체합니다.
3. 왼쪽 파일 옆 + 버튼 -> HTML -> 파일 이름 Index (확장자 빼고) -> Index.html 내용 전체 붙여넣기.
4. 저장 후 상단 함수 목록에서 setupDashboard 선택 -> 실행 -> 요청되는 구글 권한 승인.
5. Google Drive에서 'CMED WORK HUB - 사이트 관리' 시트를 엽니다.
6. 사이트목록 시트에서 A열 카테고리 / B열 사이트명 / C열 URL / D열 설명 / E열 사용여부(Y 또는 N)를 관리합니다.
7. Apps Script의 배포 -> 새 배포 -> 웹 앱을 선택합니다.
   실행 사용자: 나(공용 Google 계정).
   액세스 권한: 회사 보안 정책에 맞게 선택.
   직원들이 공용 계정으로 로그인할 경우 해당 계정으로 접속할 수 있게 설정합니다.
8. 발급된 웹 앱 주소(/exec)를 복사하여 직원 PC의 즐겨찾기/시작 페이지로 지정합니다.

[수정/동기화]
- 관리자 시트에서 사이트 목록을 수정하면 직원 화면에 약 60초마다 반영됩니다(화면이 열려 있는 경우).
- 코드를 수정하면 '배포 관리 -> 수정 -> 새 버전'으로 갱신해야 직원들이 같은 주소에서 수정본을 보게 됩니다.
- 네트워크나 Google 서비스에 따라 60초보다 늦을 수 있습니다.

[안내]
- 로고는 Index.html에 포함되어 별도 이미지 업로드가 필요 없습니다.
- 직원 모두 같은 구글 계정으로 시트에 접근하면 누구나 편집할 수 있으므로 계정/권한 보안을 점검하세요.
- 관리 시트에는 암호, 고객 정보 등을 넣지 마세요.
